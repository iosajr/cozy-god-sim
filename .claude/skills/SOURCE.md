# Source

These skills are copied from https://github.com/mattpocock/skills (MIT licensed)
by Matt Pocock, commit-pinned at the time this project was scaffolded.

To update them later, re-run:

    npx skills@latest add mattpocock/skills

or re-clone the repo and copy `skills/engineering` and `skills/productivity` here.

Run the `setup-matt-pocock-skills` skill once (ask Claude Code to run it, or
just say "set up matt pocock skills") to configure issue tracker, triage
labels, and doc preferences for this repo.
